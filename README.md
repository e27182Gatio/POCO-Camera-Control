# POCO Camera Control

Aplicación de cámara Android para POCO X7 Pro: modo fotografía/video, pantalla AMOLED negra táctil con doble toque, 0.6× preferido, video 4K sujeto a compatibilidad y audio.

> Prototipo inicial sin compilar ni probar en el teléfono. La pantalla permanece encendida para detectar los toques; no funciona con el panel físicamente apagado.

## Código fuente

El paquete original se encuentra en `POCO-Camera-Control-v0.1-source.zip`. Contiene el proyecto Android completo en la carpeta `POCO-Camera-Control/`.

Desde GitHub Actions se puede extraer el paquete y compilar el APK de depuración mediante el flujo de trabajo `android-debug.yml`. No se garantiza una compilación exitosa hasta pasar las pruebas.
